# Frozen Windows workflow backups

The files under `workflow-backups/windows/` are byte-for-byte copies of the
32 Windows workflow files from `Vinylofy/Vinylofy` at migration time. They are
outside `.github/workflows/`, so GitHub does not schedule or execute them.

Those 32 workflows represent 28 unique shops. Some shops have more than one
Windows workflow already (for example separate listing and EAN workflows).
